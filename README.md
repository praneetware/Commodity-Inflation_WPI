## 📊 India WPI (Wholesale Price Index) Dashboard

An interactive, responsive data analytics dashboard that visualizes India's Wholesale Price Index (WPI) time-series data spanning from **2012 to 2023** across hundreds of commodities. 

### 🌐 Data Source
The underlying dataset represents official macroeconomic data sourced directly from [Data.gov.in — Wholesale Price Index Catalog](https://www.data.gov.in/catalog/wholesale-price-index-1) (Base Year: 2011–12).

### 🚀 Key Features
* **Granular Commodity Search:** Instant search and look-up capabilities covering over 800 distinct commodities and economic codes.
* **Smart Categorization & Insights:** Automatically filters items into data-driven tabs highlighting economic trends:
  * **📈 Top Gainers / Losers:** Tracks commodities experiencing the sharpest percentage price changes.
  * **⚡ Volatile Items:** Flags commodities with the highest statistical standard deviation (unstable pricing).
  * **⚖️ Heavy Weights:** Highlights the high-impact base items driving core inflation indexes.
* **Interactive Time-Series Charting:** Leverages **Chart.js** to render clean, hoverable historical data trends for any selected commodity over a 10+ year timeline.
* **Zero-Backend Architecture:** Implements a highly optimized, single-page browser experience featuring dynamic dark mode support seamlessly mimicking modern UI design guidelines.
